# Proyecto 3 - Power BI

## Análisis comercial de Pétalo - Caso 13

### Objetivo
Analizar la evolución de las ventas y la rentabilidad de Pétalo, identificando oportunidades de mejora comercial por producto, categoría y sucursal.

### Datos
- Fuente: base de datos académica del caso 13, Pétalo.
- Período: enero de 2024 a diciembre de 2025.
- Frecuencia del análisis: mensual.
- Registros originales: 3.261.
- Registros después de la limpieza: 3.189.
- Productos: 12.
- Sucursales: 5.

### Metodología
- Limpieza y transformación de datos mediante Power Query.
- Eliminación de registros duplicados.
- Estandarización de categorías.
- Modelamiento y relaciones entre tablas.
- Creación de medidas mediante DAX.
- Elaboración de un dashboard interactivo.

### Principales resultados
- Crecimiento anual de las ventas de 1,73%.
- Margen bruto total de 33,86%.
- Caída de las ventas de Las Condes de 59,67% entre julio y septiembre de 2025 respecto del mismo período de 2024.
- Monstera lideró las ventas, pero presentó un margen bruto de solo 3,85%.
- Macetas fue la categoría con mayor crecimiento, alcanzando un 45,07%.

### Instrucciones de ejecución
1. Descargar el archivo PBIX y la base de datos Excel.
2. Abrir el archivo PBIX en Power BI Desktop.
3. En caso de actualizar los datos, verificar la ruta del archivo Excel.
4. Explorar las visualizaciones y los filtros interactivos.

Se adjunta también el informe con las principales conclusiones y recomendaciones para la gerencia.
