# Portafolio de análisis de series de tiempo

**Autora:** Sofía Rojas  
**Año:** 2026

## Introducción

Este portafolio reúne cuatro proyectos desarrollados durante el semestre, utilizando distintas herramientas de análisis, procesamiento y visualización de datos.

El objetivo es analizar el comportamiento temporal de distintas variables económicas y comerciales, identificando tendencias, patrones estacionales, anomalías y oportunidades de mejora.

## Proyectos

| Herramienta | Proyecto | Período |
|---|---|---|
| [Python](01_Python/) | Fuerza de trabajo nacional e inactivos en Chile | 2020-2026 |
| [R](02_R/) | Inflación interanual en Chile | 2011-2026 |
| [Power BI](03_Power_BI/) | Análisis comercial de Pétalo | 2024-2025 |
| [Tableau](04_Tableau/) | Evolución de ventas y rentabilidad de Pétalo | 2024-2025 |

## Estructura del repositorio

Cada carpeta contiene los archivos correspondientes al proyecto, sus bases de datos y un README con la descripción del análisis, la metodología, los principales resultados y las instrucciones de ejecución.

## Herramientas utilizadas

- Python: preparación de datos, descomposición temporal y pruebas estadísticas.
- R: análisis de tendencias, promedios móviles y visualización de series de tiempo.
- Power BI: transformación de datos, modelamiento, medidas DAX y análisis comercial.
- Tableau: visualización interactiva, análisis temporal y evaluación de rentabilidad.

## Conclusión

El desarrollo de estos proyectos permitió comprender las distintas aplicaciones del análisis de series de tiempo, tanto en el contexto macroeconómico como en la toma de decisiones empresariales.

Las cuatro herramientas presentan fortalezas complementarias y permiten abordar el análisis de datos desde distintas perspectivas.
