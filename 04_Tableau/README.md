# Proyecto 4 - Tableau

## Análisis de la evolución de ventas de Pétalo - Caso 13

### Objetivo
Analizar la evolución de las ventas de Pétalo durante 2024 y 2025, identificando patrones estacionales y evaluando la contribución de las distintas categorías y sucursales a las ventas y la rentabilidad del negocio.

### Datos
- Fuente: base de datos académica del caso 13, Pétalo.
- Período: enero de 2024 a diciembre de 2025.
- Frecuencia del análisis: mensual.
- Registros originales: 3.261.
- Registros después de la limpieza: 3.189.

### Metodología
- Revisión de los tipos de datos.
- Eliminación de 72 registros duplicados.
- Estandarización de categorías.
- Creación de campos calculados para ventas, costos, utilidad bruta y margen bruto.
- Análisis de la evolución mensual de las ventas.
- Elaboración de un dashboard interactivo.

### Principales resultados
- Las ventas aumentaron un 1,73% entre 2024 y 2025.
- El margen bruto disminuyó de 34,02% a 33,69%.
- Se identificaron mayores ventas durante febrero y mayo en ambos años, lo que sugiere un comportamiento estacional.
- Mayo de 2025 presentó el mayor nivel de ventas, alcanzando $8.979.240.
- Arreglos fue la categoría con mayor margen bruto, alcanzando un 45,20%.
- Plantas presentó un margen bruto de solo 13,94%.
- Las Condes lideró las ventas y la utilidad bruta del período.

### Conclusión
Un mayor volumen de ventas no necesariamente implica una mayor rentabilidad. Se recomienda priorizar las categorías más rentables y revisar la estructura de costos y precios de aquellas con menores márgenes.
